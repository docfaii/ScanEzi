## ScanEzi 2.0

ScanEzi can now update itself.

### What's new

- **Built-in updates** — on launch ScanEzi checks GitHub Releases for a newer version, downloads the package that matches your installation (self-contained or framework-dependent) and installs it when you restart. Update checks and progress live in the new **UPDATES** section in Settings.
- **Automatic or manual** — automatic checks are on by default and can be switched off. The **Check for updates** button always works, even when automatic checks are disabled.
- **Verified downloads** — the downloaded package is checked against the SHA-256 digest published with the GitHub release before it is installed.
- **Release automation** — pushing a `v*` tag now builds both Windows x64 packages and publishes them to GitHub Releases automatically.

### Fixes

- The hardware Scan button now uses the WIA `IWiaDevMgr` callback API, so pressing the button on the scanner starts a scan reliably.

### Downloads

| File | Notes |
|------|-------|
| `ScanEzi-2.0.0-win-x64-self-contained.zip` | Nothing else to install. Unzip and run `ScanEzi.exe`. |
| `ScanEzi-2.0.0-win-x64.zip` | Smaller. Requires the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). |

Both builds are unsigned, so Windows SmartScreen may warn on first run. There is no installer, and ScanEzi writes only to your user profile.

### Upgrading from 1.0.0

Download the package that matches the build you already use and unzip it over the existing folder, or let 2.0 update itself from here on.
