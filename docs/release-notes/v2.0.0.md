## ScanEzi 2.0

ScanEzi now ships as an installer and can update itself.

### What's new

- **Installer** — `ScanEzi-2.0.0-setup.exe` installs ScanEzi for the current user, adds Start menu and optional desktop shortcuts, registers an uninstaller in Windows settings and needs no .NET runtime (everything is bundled). No administrator rights required.
- **Built-in updates** — on launch ScanEzi checks GitHub Releases for a newer version, downloads the right package for your copy and installs it when you restart. Update checks and progress live in the new **UPDATES** section in Settings. Installed copies update through the installer, so shortcuts and the uninstaller stay current; portable copies update in place.
- **Automatic or manual** — automatic checks are on by default and can be switched off. The **Check for updates** button always works, even when automatic checks are disabled.
- **Verified downloads** — the downloaded package is checked against the SHA-256 digest published with the GitHub release before it is installed.
- **Release automation** — pushing a `v*` tag now builds the installer and both Windows x64 packages and publishes them to GitHub Releases automatically.

### Fixes

- The hardware Scan button now uses the WIA `IWiaDevMgr` callback API, so pressing the button on the scanner starts a scan reliably.

### Downloads

| File | Notes |
|------|-------|
| `ScanEzi-2.0.0-setup.exe` | **Recommended.** Installs for the current user; no .NET runtime needed. |
| `ScanEzi-2.0.0-win-x64-self-contained.zip` | Portable. Nothing else to install — unzip and run `ScanEzi.exe`. |
| `ScanEzi-2.0.0-win-x64.zip` | Smallest portable build. Requires the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). |

The installer and the builds are unsigned, so Windows SmartScreen may warn on first run. ScanEzi writes only to your user profile.

### Upgrading from 1.0.0

Run the installer — it replaces any earlier unpacked copy. From 2.0 onwards ScanEzi can update itself.
