## ScanEzi 2.1

Quality-of-life release: you can now start over in one click and decide page by page what gets saved,
and the scanner settings work the moment the window opens.

### What's new

- **New Scan button** — clears the gallery and starts fresh without closing the app. The pages that
  were in the gallery are deleted from the temporary folder, so nothing is left behind.
- **Tick the pages you want to save** — every thumbnail now carries a checkbox. Empty pages (the
  all-black frames a duplex pass produces, and fully blank sheets) start **unticked** so a careless
  save never picks them up, but a single click includes them. The save button counts what will be
  written, e.g. **Save 3 pages as PDF…**, and the status line keeps a running
  *"4 of 6 page(s) will be saved"*. Unticked pages stay visible in the gallery with a **Not saved**
  overlay, and the choice survives preview edits and rotation.
- **Empty pages → Untick / Keep** — the old *Discard* switch is now a plain choice of what a freshly
  scanned empty page should start as. *Keep* ticks empty pages as they arrive for people who want to
  review them by hand.

### Fixes

- **Scanner options no longer greyed out at launch.** On some drivers the first capability query
  after a device is enumerated comes back empty, which left **Sides** and **Source** disabled until
  you pressed Refresh. Capability reads now retry with a short backoff, stale answers from a
  previous device can no longer overwrite the current one, and if a driver simply refuses to report
  its options the controls stay usable instead of being locked out.
- **HP Easy Scan error dialog suppressed.** Printers and all-in-ones that register an HP STI scan
  button make Windows launch `SDSSLchr.exe` on the hardware Scan button; when the *HP Easy Scan*
  application itself is not installed, that produces a "This button is configured to launch the HP
  Easy Scan Software" error box on top of every scan. ScanEzi now watches for that specific dialog
  and closes it, so pressing the button on the scanner just starts a scan.

### Downloads

| File | Notes |
|------|-------|
| `ScanEzi-2.1.0-setup.exe` | **Recommended.** Installs for the current user; no .NET runtime needed. |
| `ScanEzi-2.1.0-win-x64-self-contained.zip` | Portable. Nothing else to install — unzip and run `ScanEzi.exe`. |
| `ScanEzi-2.1.0-win-x64.zip` | Smallest portable build. Requires the [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). |

The installer and the builds are unsigned, so Windows SmartScreen may warn on first run. ScanEzi
writes only to your user profile.

### Upgrading

Installed copies update themselves: ScanEzi checks GitHub Releases on launch, offers 2.1 and applies
it on restart. You can also download `ScanEzi-2.1.0-setup.exe` and run it over the existing install.
Portable copies can either be replaced by unzipping the new build or updated in place from inside the
app.

> The HP Easy Scan dialog is closed rather than unregistered: the button handler lives in a
> machine-wide (`HKLM`) Still Image registration that a per-user app cannot remove. The dialog is
> dismissed before it can interrupt a scan.
